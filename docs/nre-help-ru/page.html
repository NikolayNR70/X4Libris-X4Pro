Поля и ориентация

Поля регулируются числовыми значениями в пикселях. Повторный выбор отмеченного значения снимает явное изменение полей: для книги применяется общий профиль, для общего профиля — исходное поведение.

Ориентация остаётся общей настройкой устройства. Её изменение не переопределяет стили абзацев и заголовков EPUB.
