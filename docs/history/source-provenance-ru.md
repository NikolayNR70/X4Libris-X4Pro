# История происхождения исходников

Этот файл — архивная техническая запись, не название продукта и не указание на официальный статус или одобрение сторонней прошивки.

Снимок исходников, из которого восстановлен текущий проект X4Libris v1.0, происходил от локально сохранённого дерева X4Pro на базе Witchhunt 3.1.3. Это происхождение нельзя честно удалить из истории или лицензий; бинарный файл сам по себе не позволяет восстановить исходный код. X4Libris использует собственные имя, версию, репозиторий, канал стабильных обновлений и релиз веб-пакета.

Сохранять лицензии и авторские уведомления включённых компонентов обязательно. Этот архив отделяет происхождение кода от текущей маркировки и инфраструктуры продукта.
