Witchhunt-NREdition.v1.1 — инструкция для Xteink X4 Pro

СТАТУС
Сборка и проверки выполняются без установки на физическое устройство. Аппаратная установка разрешается только после отдельного согласия владельца. Файл firmware.factory.bin и полные образы эмулятора не являются инструкцией для прошивки реальной читалки.

ОФОРМЛЕНИЕ
Откройте меню оформления и выберите область: текущая книга либо все книги.
Выберите значение нужного свойства. Повторный выбор отмеченного значения отменяет это изменение.
Для текущей книги отмена означает наследование общего профиля. Для общего профиля отмена возвращает исходный стиль EPUB. Чтобы полностью вернуть стили книги, отмените явные изменения соответствующего свойства в обеих областях.
Исходное оформление не заменяется условными 100%: снова применяются собственные стили каждого элемента EPUB. Старые настройки v1 читаются без сброса. Старый явно нулевой отступ остаётся нулевым.
Шрифты и остальные настройки, которые в v1 не имели режима исходного CSS, сохраняют свои прежние элементы управления.

ПЕРЕНОСЫ
Разрешённый перенос слова допускается между страницами. Ограничение CSS hyphens:none и выключение переносов пользователем сохраняются. Старые кэши разделов пересчитываются автоматически при первом открытии.

POWER
Не изменены аппаратные пороги и жесты включения. Ускорена полная программная проверка прошивки и убрана фиксированная пауза USB. Реальное время включения следует измерять отдельно после разрешения аппаратного испытания.

ОТКАТ
При обычном OTA-обновлении должна сохраняться проверенная предыдущая прошивка в другом OTA-разделе. Защита проверяет образы, отслеживает первый запуск, ошибки и отзывчивость интерфейса. После 30 секунд исправной работы принятие происходит автоматически. При преждевременном повторном запуске либо тайм-ауте используется резервная прошивка. Отдельный экран подтверждения не нужен.
Чистый образ приложения без резервного раздела не проверяет сценарий отката. Не затирайте NVS, таблицу разделов или резервную прошивку ради установки.

ПРОВЕРКА ФАЙЛОВ
Перед будущей установкой сравните SHA-256 с SHA256SUMS-Witchhunt-NREdition.v1.1.txt. Используйте BIN приложения только для X4 Pro, штатный поддерживаемый путь обновления и имеющуюся рабочую резервную прошивку. Конкретная аппаратная процедура и разрешение на неё согласуются отдельно.
