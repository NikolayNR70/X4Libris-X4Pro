Изменения версии 3.1.1

ОбластьИзменение
FB2 ZIPДобавлено открытие обычных ZIP-архивов с книгой FB2 из обзора файлов. FB2 читается как FB2, без преобразования в EPUB; временные данные располагаются в /.crosspoint/tmp.
KOReader SyncСохранена поддержка прямого сопоставления прогресса FB2 при загрузке с сервера.
ПриложенияИз прошивки удалён код игр. Остались Clock, Calculator и Today. Идентификаторы приложений сохранены для совместимости существующих настроек.
EPUBОбработка EPUB остаётся отдельной от FB2; проверяйте её по разделу тестов для этого выпуска.
Память EPUBПеред пакетной обработкой больших книг проверяется доступная память с учётом фрагментации. Если её мало, используется более медленный резервный поиск вместо рискованного выделения крупных таблиц.
