Абзацы и интервалы

Отдельного пункта «Как в книге» нет. Выберите нужное выравнивание, интервал или отступ. Чтобы отменить эту настройку, выберите отмеченное значение повторно.

Для текущей книги отмена возвращает значение общего профиля. В общем профиле отмена восстанавливает исходное оформление EPUB. Когда все изменения отменены в обеих областях, используются стили книги.

Старые настройки v1 читаются без изменения числовых значений: 0% отступа остаётся явным нулём; исходный стиль и наследование сохраняются.
