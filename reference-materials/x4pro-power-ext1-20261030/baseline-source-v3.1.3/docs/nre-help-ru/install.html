Файл прошивки и установка

Выпуск содержит файл приложения X4Libris-X4Pro-v3.0.0-direct-fb2-20261023.bin только для Xteink X4 Pro. Это не полный образ устройства, не образ SD-карты и не установщик для других моделей.
