Меню оформления

В меню чтения откройте «Настройки», затем «Быстрые настройки». Область «Текущая книга» меняет только эту книгу, область «Все книги» — общий профиль.

Доступны разделы шрифта и размера, переносов, абзацев и интервалов, заголовков, полей и ориентации, дополнительных параметров и всех настроек чтения.

У выравнивания, интервалов, отступов, заголовков и полей нет отдельного пункта «Как в книге». Повторный выбор отмеченного значения отменяет соответствующее изменение. Для книги возвращается общий профиль; для общего профиля восстанавливается исходный стиль EPUB. Сброс одного свойства не отменяет остальные изменения.

Шрифт и свойства, которые не имели режима исходного CSS в v1, сохраняют прежние элементы управления. Старые настройки читаются без массового сброса.
