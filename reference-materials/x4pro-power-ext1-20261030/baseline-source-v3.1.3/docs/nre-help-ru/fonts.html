Шрифт и размер текста

Можно выбрать встроенный шрифт читалки, установленное семейство или добавить собственный шрифт TTF/OTF через менеджер шрифтов. При установке файл преобразуется в формат шрифта читалки и сохраняется на SD. Список размеров зависит от выбранного семейства.

Размер устройства задаёт базовый размер текста. Относительные и абсолютные значения CSS также участвуют в разметке. Дополнительно доступна нормализация размеров шрифта.

Шрифты, встроенные внутрь EPUB, не используются. Применяется выбранный шрифт устройства.
