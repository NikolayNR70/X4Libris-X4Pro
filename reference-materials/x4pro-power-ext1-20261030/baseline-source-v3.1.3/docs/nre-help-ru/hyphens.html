Переносы слов

Переносы обычного текста включены по умолчанию и не требуют общей галочки переопределения оформления.

Учитываются hyphens: none, manual, auto, варианты с префиксами -webkit- и -epub-, наследование и приоритет правил.

hyphens: none запрещает автоматическое разбиение соответствующего текста.

В h1–h6 и распознаваемых блоках .title, .subtitle, .heading-1, .heading-2 переносы запрещены независимо от общего переключателя.

X4Libris-X4Pro-v3.1.1 · Xteink X4 Pro · Справка к выпуску

В v1.1 обычные разрешённые переносы сохраняются и на последней строке страницы. Граница страницы больше не отключает переносы. Настройка переноса и CSS hyphens:none продолжают действовать.
