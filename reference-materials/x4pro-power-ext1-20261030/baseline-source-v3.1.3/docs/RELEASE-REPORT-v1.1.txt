Witchhunt-NREdition.v1.1 — отчёт о выпуске
Дата: 17 октября 2026. Платформа: Xteink X4 Pro. Среда: RDK alex-prime, Ubuntu.

РЕЗУЛЬТАТ
Собрана прошивка приложения X4 Pro. Проверки выполнены до любых испытаний на физическом устройстве. На читалку ничего не установлено.

ИСПРАВЛЕНИЯ
1. Убраны явные пункты «Как в книге». Повторный выбор отмеченного значения снимает соответствующее изменение. В области книги возвращается общий профиль; в общем профиле — исходный стиль EPUB. Значения v1 не перенумерованы и не сбрасываются: -1 сохраняет наследование, 0 сохраняет исходный стиль для полей ReaderFormatting, явный 0% отступ остаётся отдельным переопределением. Не подставляется условный универсальный стиль 100% вместо разных стилей EPUB. Шрифты и прочие свойства без режима исходного CSS сохраняют прежнее управление.
2. Убрано требование повторно рассчитывать последнюю строку страницы без переносов. Оно переносило целое слово на следующую страницу и растягивало оставшиеся пробелы. Кэш раздела обновлён до версии 82. CSS hyphens:none и пользовательское выключение переносов сохранены.
3. Подтверждена программная задержка до появления интерфейса: полный программный SHA-256 образа на каждом запуске. Проверка перенесена с WolfSSL на штатный порт mbedTLS ESP-IDF с CONFIG_MBEDTLS_HARDWARE_SHA. Все байты текущей и резервной прошивок по-прежнему проверяются. Убрана также фиксированная пауза USB 250 мс для X4 Pro. Порог Power 300 мс, debounce 30 мс, окно двойного нажатия 300 мс, линии питания и загрузчик не изменены.
4. Эмулятор обнаружил дополнительную ошибку восстановления: известная исправная резервная прошивка помечалась NEW, и загрузчик мог пометить её ABORTED при следующем сбросе. Только при возврате на полностью проверенную резервную прошивку теперь записывается VALID. Новые установки сохраняют NEW и испытательный первый запуск. Экран подтверждения не добавлен.

ПРОВЕРКИ
• pio run -e x4pro_gh_release: SUCCESS на alex-prime.
• EpubPipelineTest: 658 тестов, 655 успешно, 3 пропущены, ошибок нет. Пропущены тест с отсутствующей внешней книгой и два варианта проверки checkpoint прогрессивного JPEG.
• Новый регрессионный тест одинаковых переносов и позиций слов при разной высоте страницы: FAIL на исходном парсере v1; PASS после исправления.
• SettingInfoOptionsTest: 7 успешно, включая отсутствие ложной активной опции при исходном/унаследованном оформлении.
• Старые проверки из develop: 11 Python-проверок и 5 отдельных C++ программ успешно. Это контракты совместимости и вспомогательных алгоритмов; сами по себе они не заменяют проверку интерфейса.
• Реальный FirstBootGuard и OtaBootSwitch проверены с постоянными моделями flash/NVS и точным итоговым BIN: принятие, повторные запуски, тайм-аут, прерывание, повторная установка, повреждение образов, отказ NVS и отказ переключения. Байты OTA-приложений при откате не изменяются.
• Проверка здоровья интерфейса: 30 секунд отзывчивой отрисовки, остановка отсчёта при зависании; ручная FirstBootActivity не подключена к запуску.
• Native eink-qemu 0.6.0, X4 Pro, панель UC8279-68, ghosting off, turbo. Архивы эмулятора сверены с SHA-256 выпуска.
• Точный итоговый образ с отдельным проверенным резервным OTA-разделом: автоматическое принятие после 30 секунд, затем успешный повторный запуск.
• Прерывание испытательного запуска: автоматический возврат, два последующих сброса, наивысшая корректная запись OTA выбирает ota_1 со статусом VALID.
• Интерфейс: EPUB с разными стилями заголовка и абзаца, открытие меню, включение выравнивания Left и его отмена повторным выбором. Снимки страницы до изменения и после отмены пиксельно идентичны: 3b9c7dc4b5d586eeec192df629ed9757a1029299d7cdae366541d187a3af48f8.
• Последняя строка тестовой страницы допускает перенос; снимки включены в доказательства.

POWER: ИЗМЕРЕНИЯ И ГРАНИЦЫ
В одинаковой модели эмулятора этап до основной инициализации с программным SHA занимал 4072 мс, с ускоряемым SHA — 1453 мс. После принятого испытательного запуска итогового BIN измерено 1462 мс; полный setup — 2088 мс. Первый испытательный запуск дольше, поскольку проверяется также резервный образ. Это гостевое время эмулятора в turbo, не измерение физической кнопки. Нельзя утверждать, что этими цифрами доказано реальное время включения читалки. Электрическая исправность и поведение OEM-контроллера питания требуют отдельного разрешённого аппаратного испытания.

ОГРАНИЧЕНИЯ
Браузерный вариант eink-qemu в этой сессии останавливался до приложения как на v1.1, так и на контрольной v1. Поэтому успешные проверки выполнены отдельным native-эмулятором на alex-prime. Аппаратных испытаний нет. Прочие сценарии, не перечисленные выше, не объявляются проверенными.
