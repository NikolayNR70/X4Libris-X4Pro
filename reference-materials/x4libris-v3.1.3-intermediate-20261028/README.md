# Точная копия промежуточной прошивки X4Libris v3.1.3

Эта ветка — архивный справочный снимок, отдельный от основной ветки `main`. Папка `source/` скопирована без изменения содержимого из промежуточного проекта от 28.10.2026. В ней 2 737 файлов, всего 149 132 765 байт.

Точность копии проверена сравнением SHA-256 каждого исходного файла. Полный манифест находится рядом в `SHA256SUMS.txt`.

Не использовать эту историческую копию вместо текущей основной прошивки и не сливать её в `main` автоматически. Начинать восстановление после чистой установки ПК с клонирования репозитория и перехода на ветку `reference/x4libris-v3.1.3-intermediate-20261028`.

Репозиторий публичный. Ради точности копия сохранена без редактирования; в одном исходном документе остаётся старый локальный путь Windows. Секретных файлов `.env`, Wi-Fi-настроек и файлов учётных данных в папке нет.
