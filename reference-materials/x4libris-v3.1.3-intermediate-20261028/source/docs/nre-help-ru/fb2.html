Чтение FB2

Открытие книги

Скопируйте на SD-карту файл .fb2, .fb2.zip или .fbz и откройте его из библиотеки. Архив можно открыть без предварительной распаковки. В нём должен быть ровно один файл с расширением .fb2; архивы с несколькими FB2 или без FB2 не открываются.

Читалка разбирает FB2 непосредственно. Исходный файл и имя не меняются, файл не скрывается и не переименовывается. При первом открытии создаётся внутренний кэш в /.crosspoint/tmp/fb2-reader-v3-…. Он нужен для страниц, изображений и быстрого повторного открытия и не является EPUB.

Содержание и оформление

Сохраняются структура разделов и порядок текста, заголовки разных уровней, абзацы, встроенные стили и поддерживаемые правила CSS, выделение текста, стихи, цитаты, эпиграфы, ссылки, сноски и встроенные изображения. Поддерживаются кодировки UTF-8, Windows-1251 и UTF-16LE/BE.

Параметры шрифта и страницы применяются общим экраном чтения. Сложная авторская вёрстка может отличаться от настольной программы: движок поддерживает нужное книгам подмножество разметки и CSS, а не весь браузерный стандарт.

Исходник, кэш и EPUB

Прогресс и закладки сохраняются для исходного FB2. EPUB открывается независимо своим обработчиком и использует собственные данные чтения. Открытие FB2 не создаёт EPUB-книгу, не создаёт EPUB-кэш и не изменяет уже имеющийся EPUB.

Кэш можно удалить через средства очистки данных читалки; исходная книга при этом не удаляется. После очистки он будет создан заново при следующем открытии.

Ограничения архивов

Архив должен быть корректным ZIP и содержать одну книгу FB2. Содержимое проверяется по заявленному размеру и CRC. Архивы с повреждёнными данными, несколькими FB2 или распакованным размером свыше 128 МиБ отклоняются. Исходный архив остаётся без изменений.
